# Тестовое задание

## Информация о компании

- **Позиция:** Frontend Developer / React Senior

## Цель

Проверка:

- чистоты и структуры кода
- выбора и обоснованности технических решений
- умения работать со стором, оптимизацией и данными
- навыка построения UI (верстка, компоненты, пагинация, обработка пустых состояний)

## Вводные данные

### API

- **Swagger-документация:** [https://api-test.rtbpanda.tech/api](https://api-test.rtbpanda.tech/api)
- **Ручка для получения данных:** [https://api-test.rtbpanda.tech/list](https://api-test.rtbpanda.tech/list)

Пагинируется массив из 150 элементов. Каждый элемент содержит обязательные и опциональные элементы, например, картинку. У некоторых элементов картинки может не быть.

## Техническое задание

Сделать веб-страницу, которая:

### 1. Отображение данных

- отображает список карточек

### 2. Пагинация

- по умолчанию 10 элементов на страницу
- переключение страниц (вперёд/назад, либо выбор страницы)
- **Будет плюсом:** "бесконечный скролл"

### 3. Оформление карточек

- выводит все поля
- если есть картинка, то отобразить её
- **Будет плюсом:** лоадер пока картинка не загрузилась

### Детали реализации

- обрабатывать ошибки загрузки данных
- обрабатывать состояние загрузки (loader/spinner)
- показывать пустое состояние, если данных нет
- использовать стор для хранения данных
- учитывать производительность при работе со списками (виртуализация по желанию, но будет плюсом)

## Требования к реализации

### Технологии

- **Фреймворки / библиотеки:** рекомендуется React, Next.js
- Разделение на переиспользуемые компоненты
- Responsive-верстка (адаптивность хотя бы базовая)
- Использование современного стека
