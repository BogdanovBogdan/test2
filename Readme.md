## Запуск проекта

### Dev режим

```bash
npm install
npm run dev
```

### Build режим

```bash
npm run build
npm run preview
```

## Выбранные технологии

- **React 19** - UI фреймворк, использован согласно требованиям к тестовому заданию
- **Vite** - был выбран т.к. конфигурация минимальная, простая интеграция с react+ts, мгновенное обновление нужных модулей
- **SCSS/CSS Modules** - SCSS модули выбраны для соответствия модульной архитектуре и изоляции стилей компонентов
- **Zustand** - выбран т.к. имеет минимум бойлерплейта и оптимален для небольшого тестового задания
- **React Virtuoso** - выбрана так как конфигурация под списки с динамической высотой очень простая, а библиотека такая же популярная и поддерживаемая как мастодонты по типу react-virtualized, react-window
- **clsx** - в тестовом минимум в двух компонентах необходимо объединять классы, поэтому решил воспользоваться легковесной библиотекой под эти задачи и не джойнить строки из массивов

## Реализованные решения

- **Виртуализация** - React Virtuoso для эффективного рендеринга больших списков
- **Бесконечный скролл** - автозагрузка новых данных при достижении конца списка
- **Fallback для картинок** - автоматическая замена сломанных изображений на placeholder
- **Прелоадеры** - shimmer-эффект для изображений, spinner для загрузки данных
- обработка пустых состояний
